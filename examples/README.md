# Examples

The examples are deterministic and local. They do not require real secrets, real language models, or external services.

- `leaky-agent-demo/`: a fake agent that demonstrates policy and secret handling.
- `policies/`: editable policy examples.
- `effect-packs/`: classification-only effect-pack YAML.
- `mcp/`: stdio MCP proxy examples.
- `ci/`: CI integration snippets.
- `staged-writes/`: staged write review.
- `network/`: network policy examples.
- `commands/`: command guard examples.
